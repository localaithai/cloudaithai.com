# Product

## Register

brand

## Users

Thai SMEs and solo operators who want the Mimir Suite experience without buying an AI machine and do not require document processing to stay on-site.

## Product Purpose

Sell Mimir Suites Cloud as the fastest no-hardware entry point, while explaining per-machine seats, cloud model use, backups, and data handling honestly.

## Brand Personality

Clear, calm, and lightweight. The experience should feel like capable software that is easy to start, not an infrastructure project.

## Anti-references

- Local-AI privacy claims that say data never leaves the building.
- Legacy Flowise installation or automation-package positioning.
- Credit, token, or tier pricing before billing is decided.
- Cloud imagery that obscures where document text is processed.

## Design Principles

- Show the Suite and the jobs it completes.
- State cloud model use and PII redaction plainly.
- Make one seat, one machine, and one local data store easy to understand.
- Preserve the light, precise interface and restrained motion.
- Keep the upgrade path to Local visible only where useful.

## Accessibility & Inclusion

Target WCAG 2.2 AA with semantic structure, keyboard access, visible focus, readable contrast, 44px touch targets, and reduced-motion behavior.
