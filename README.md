# CloudAI Thailand

Thai-first acquisition site for Mimir Suites Cloud. The static site describes a desktop Suite installed per machine, with independently stored seat data and cloud model choices.

The current Mimir Suites offering covers supported document, knowledge, and business workflows. Slides, Image Studio, and Video Studio have paused development and are excluded from both the Cloud and Local editions.

```bash
pnpm install
pnpm lint
pnpm build
```
