## AWS เพิ่มตัวเลือกใดให้การค้นเว็บ

AWS เพิ่ม domain filtering และ user location ให้ Bedrock Web Search วันที่ 23 ตุลาคม 2026 ตาม [ประกาศใหม่](https://aws.amazon.com/about-aws/whats-new/2026/10/bedrock-web-search-domain-user-location/) ตัวกรองกำหนดโดเมนอนุญาตหรือบล็อกได้ถึง 100 รายการ ส่วนตำแหน่งผู้ใช้ช่วยให้ผลเกี่ยวข้องกับพื้นที่

บริการค้นเว็บเดิมเปิดตัว [วันที่ 4 สิงหาคม](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-bedrock-web/) อัปเดตครั้งนี้ระบุพื้นที่บริการในสหรัฐฯ สี่แห่ง จึงต้องแยกค่าประเทศที่ใช้ค้นออกจากภูมิภาคที่ประมวลผล ไม่ใช้ค่า location เป็นหลักฐานว่าข้อมูลอยู่ในไทย

## แยกคำถามเรื่องแหล่งออกจากปลายทางข้อมูล

ข้อเสนอสำหรับ SME ที่ให้ AI ค้นข้อมูลประกอบเอกสารคือเริ่มจากคำถามหนึ่งชุด เช่น ข้อมูลผู้ขายที่ใช้เตรียมคำสั่งซื้อ แล้วกำหนดว่าแหล่งใดใช้ยืนยันข้อเท็จจริงได้ พร้อมทางส่งต่อเมื่อข้อมูลเก่าหรือไม่มีคำตอบ

| สิ่งที่ตั้งค่า | ใช้ตัดสินอะไร | หลักฐานที่ควรเก็บ |
| --- | --- | --- |
| โดเมนที่ยอมรับ | แหล่งใดอยู่ในขอบเขตค้น | รายชื่อแหล่งและเหตุผลที่เลือก |
| ประเทศหรือเมืองผู้ใช้ | ผลควรเกี่ยวกับพื้นที่ใด | คำถามเดียวกันกับค่าพื้นที่ที่ต่างกัน |
| endpoint และภูมิภาค | ข้อมูลไปประมวลผลผ่านเส้นทางใด | การตั้งค่าจริงและเงื่อนไขบริการ |
| การดึงหน้าเว็บจริง | อนุญาตให้ติดต่อเว็บภายนอกเมื่อใด | สิทธิ์ที่เปิดและผลตรวจเส้นทาง |
| การนำคำตอบไปใช้ | ข้อใดมีหลักฐานพอสำหรับงาน | URL วันที่ และผู้ตรวจคำตอบ |

ตารางนี้เป็นเกณฑ์ทดลองที่เสนอ ไม่ใช่ผลทดสอบบริการ หากจำกัดแหล่งแล้วคำตอบขาดข้อมูล ให้ส่งงานให้ผู้รับผิดชอบเลือกแหล่งเพิ่มเติมตามกระบวนการ ไม่ขยายขอบเขตอัตโนมัติเพียงเพื่อให้ได้คำตอบ

## ทดลองกรณีที่ตั้งค่าถูกแต่คำตอบยังใช้ไม่ได้

สร้างตัวอย่างที่เว็บทางการมีเอกสารเก่า มีข้อมูลหลายประเทศ หรือใช้ชื่อผลิตภัณฑ์คล้ายกัน ให้ผู้ตรวจเปิดหลักฐานแล้วตัดสินว่าข้อความในคำตอบใช้กับพื้นที่และช่วงเวลาที่ถามจริงหรือไม่ นับงานที่ผ่านการตรวจแทนการนับเพียงว่าระบบตอบได้

[คู่มือปัจจุบันของ AWS](https://docs.aws.amazon.com/bedrock/latest/userguide/web-search.html) แยกการอ่านจากดัชนีหรือ cache กับการดึงเว็บภายนอกไว้ ทีมควรตรวจการตั้งค่าและสิทธิ์จริงก่อนส่งข้อมูลลับไปค้น ส่วนวิดีโอ AgentCore เป็นบริบทปี 2025 ไม่ใช่การสาธิตตัวกรองใหม่นี้

สำหรับ Mimir Suites Cloud ข้อความเอกสารส่งไปโมเดลคลาวด์ โดยปิดบัง PII เป็นค่าเริ่มต้น ใช้ [วิธีประเมินงานบนคลาวด์](/methodology/) กำหนดข้อมูลทดสอบ เกณฑ์ผ่าน และคำถามเรื่องปลายทางก่อนเลือกบริการค้นเว็บมาประกอบงาน
