## รางวัลบอกงานหนึ่ง ไม่บอกทุกเส้นทางข้อมูล

NECTEC/NSTDA รับรางวัล GDCC Gov Cloud สำหรับงาน Pathumma วันที่ 21 สิงหาคม 2026 ข่าวกล่าวถึงโครงสร้างพื้นฐาน cloud ไม่ใช่หลักฐานประมวลผลในอาคารของผู้ซื้อ [แหล่งข่าวทางการ](https://www.nstda.or.th/archives/pathumma-llm-gdcc-gov-cloud-awards-2026/)

ผู้ซื้อระบบ AI อาจเห็นชื่อโครงสร้างพื้นฐานภาครัฐแล้วเข้าใจว่าการใช้โมเดลไทยทุกแบบมีเงื่อนไขข้อมูลเดียวกัน แต่การติดตั้งและบริการที่เลือกต่างกันได้ ให้เริ่มจากผังของ workflow คุณเอง ว่าแอปอ่านอะไร โมเดลอยู่ที่ไหนและผลถูกเก็บอย่างไร โดยไม่ใช้ชื่อโมเดลแทนตำแหน่งบริการ

## แยกแอป โมเดลและการเก็บ

ข้อวิเคราะห์คือแยกสามชั้นของงานเอกสาร บนเครื่องผู้ใช้มีแอปและข้อมูลตามการตั้งค่า ส่วนคำขอโมเดลมีปลายทางของตน และ log หรือสำรองมีขอบเขตอีกชุดหนึ่ง แต่ละชั้นควรมีเจ้าของและเงื่อนไขที่ตอบได้

| ชั้นงาน | สิ่งที่ต้องถาม |
| --- | --- |
| แอปบนเครื่อง | ข้อมูลใดอยู่ในแต่ละ install และใครอ่านได้ |
| บริการโมเดล | ส่งข้อความอะไรไปปลายทางใด |
| Log และผล | เก็บที่ไหน ระยะใดและผู้มีสิทธิ์ดู |
| สำรอง | ครอบคลุมข้อมูลใดและคืนไปเครื่องไหน |

รายการนี้เป็นวิธีตรวจขอบเขต ไม่ใช่เงื่อนไข GDCC หรือ Pathumma ที่เรารับรอง หากต้องการให้ข้อความไม่ออกจากอาคาร ให้ระบุ requirement นั้นตรง ๆ แล้วเลือกสถาปัตยกรรมที่ตอบได้

## ทดลองด้วยข้อมูลที่อนุญาต

ใช้เอกสารจำลองที่ไม่มีข้อมูลลับทดสอบหนึ่งงาน ตั้งแต่เลือกไฟล์ ปิดบังข้อมูล ส่งคำขอจนได้ผล ตรวจว่าผู้ใช้เห็นข้อมูลที่จะส่งและปลายทางเพียงพอหรือไม่ จากนั้นกำหนดรายการข้อมูลที่งานจริงอนุญาต พร้อมขั้นตรวจโดยคนก่อนเริ่มใช้

แยกการใช้งานของแต่ละเครื่องผู้ใช้ให้ชัด Mimir Suites Cloud เป็น Suite บนเครื่องเดิม ใช้โมเดล cloud และไม่ต้องซื้อฮาร์ดแวร์ AI แต่ละ seat มี install และข้อมูลของตน การสำรองจึงต้องวางตามเครื่องและเจ้าของข้อมูล ไม่เดาว่าเป็นคลังร่วมอัตโนมัติ

## เลือก Cloud ด้วยข้อมูลที่ตรงจริง

[Pathumma LLM เทคโนโลยีพัฒนา AI ที่เข้าใจบริบทและวัฒนธรรมไทย](https://www.youtube.com/watch?v=5ZlCbIANVHc) ของ NECTEC เป็นวิดีโอ NECTEC จากปี 2025 ใช้เป็นพื้นหลัง Pathumma ไม่ใช่ภาพรางวัลปี 2026 หรือหลักฐานวิธีส่งข้อมูลของ Mimir Suites Cloud

ข้อความเอกสารใน Mimir Suites Cloud ถูกส่งไปโมเดล cloud โดยปิดบัง PII เป็นค่าเริ่มต้น ยังต้องตรวจข้อมูลที่เหลือและนโยบายงาน การปิดบังไม่ได้รับรองความนิรนามหรือการปฏิบัติตามกฎหมายครบถ้วน บทความนี้ไม่ยืนยันว่า Pathumma รวมใน Suite

เตรียมผังข้อมูลและขอบเขตที่อนุญาตก่อนอ่าน [วิธีทำงานของ Mimir Suites Cloud](/how-it-works/)
