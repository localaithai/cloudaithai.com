## Anthropic แยกการถอนแอปกับการล้างความจำ

[ประกาศความปลอดภัย Duet วันที่ 23 ตุลาคม 2026](https://claude.com/resources/articles/claude-duet-safety-privacy-and-security) ระบุว่าการถอดแอปหยุดการเข้าถึงใหม่ แต่สิ่งที่เรียนรู้ไว้ยังคงอยู่จนรีเซ็ตความจำ ประวัติและความจำจึงต้องจัดการแยกจากสิทธิ์เชื่อมต่อ [รายการประกาศทางการ](https://claude.com/resources/product-announcements) ระบุวันเผยแพร่รายละเอียดนี้

Duet ยังเป็น research preview ตามการเปิดตัวเดิม ไม่ได้ยืนยันสิทธิ์ใช้งานในไทย รายละเอียดใหม่นี้เหมาะใช้ตั้งคำถามก่อนนำข้อมูลธุรกิจเข้าไปทดลอง

## ทำรายการออกจากบริการตามชนิดข้อมูล

ข้อเสนอสำหรับ SME คือทำบัญชีแอปและข้อมูลที่อนุญาตตั้งแต่เริ่มทดลอง เมื่อพนักงานเปลี่ยนหน้าที่หรือหยุดใช้บริการ จะได้ตัดสินว่าต้องถอนสิทธิ์และจัดการข้อมูลส่วนใด

| รายการที่ตรวจ | การตัดสินที่ต้องแยก | หลักฐานหลังทำ |
| --- | --- | --- |
| การเชื่อมต่อแอป | หยุดการเข้าถึงครั้งใหม่ | รายการที่ถอดและผู้รับผิดชอบ |
| ความจำของ Agent | ข้อมูลใดไม่ควรใช้ต่อ | การตั้งค่าและผลตรวจด้วยข้อมูลจำลอง |
| ประวัติการสนทนา | สิ่งใดต้องเก็บหรือนำออก | รายการที่ดำเนินการตามขั้นตอน |
| ผลงานที่ส่งออก | มีสำเนาอยู่ที่ใดบ้าง | เจ้าของไฟล์และผู้รับที่ต้องติดตาม |
| งานที่ยังค้าง | ใครรับช่วงหรือยกเลิก | สถานะที่ตรวจได้และผู้ยืนยัน |

ตารางนี้เป็นรายการบริหารข้อมูลที่เสนอ ไม่ใช่คำรับรองว่าตัวเลือกเดียวลบสำเนาจากทุกปลายทาง ทดลองการออกจากบริการด้วยข้อมูลที่ไม่ลับก่อนใช้กับงานจริง

## เปรียบเทียบกับข้อมูลในแต่ละ seat

Mimir Suites Cloud ติดตั้งแยกต่อเครื่อง ข้อความเอกสารส่งไปโมเดลคลาวด์โดยปิดบัง PII เป็นค่าเริ่มต้น เจ้าของงานยังต้องรู้ว่าข้อมูลที่อนุญาตส่งและไฟล์ผลลัพธ์อยู่ที่ใด การรีเซ็ตข้อมูลบริการอื่นไม่แทนขั้นตอนของแต่ละ seat
