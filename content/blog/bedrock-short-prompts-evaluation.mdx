## AWS เพิ่มตัวเลือก prompt shortening

AWS เพิ่ม [prompt shortening ใน Advanced Prompt Optimization](https://aws.amazon.com/about-aws/whats-new/2026/10/bedrock-prompt-optimization-shortening/) วันที่ 20 ตุลาคม 2026 ตรงกับ [ประวัติเอกสาร](https://docs.aws.amazon.com/bedrock/latest/userguide/bedrock-ug-doc-history.html) เป็นตัวเลือกต่อ template และคืนฉบับย่อเมื่อสั้นกว่าโดยคะแนนประเมินไม่ลด มิฉะนั้นใช้ฉบับเดิม

ผลคะแนนนั้นใช้กับเกณฑ์และข้อมูลที่เลือกประเมิน ไม่ได้ยืนยันว่าทุกคำขอในงานจริงจะรักษาคุณภาพหรือประหยัดเท่ากัน

## เก็บเงื่อนไขงานก่อนลดคำ

ข้อเสนอสำหรับธุรกิจไทยคือแยกชุดที่ใช้ปรับ prompt ออกจากชุดตรวจรับ ใช้คำถามและเอกสารชุดเดียวกันเปรียบเทียบฉบับเดิมกับฉบับย่อ พร้อมผู้ตรวจที่รู้ว่าความผิดแบบใดทำให้งานใช้ไม่ได้

| จุดเปรียบเทียบ | ตัวอย่างที่ควรเก็บ | เกณฑ์ตัดสิน |
| --- | --- | --- |
| ข้อห้ามสำคัญ | งานที่คำขอชนกับกฎ | ไม่ข้ามข้อห้ามหลังย่อ |
| ข้อยกเว้น | คำขอหายากแต่ต้องรับมือ | ยังเลือกทางออกถูก |
| ภาษาไทย | ตัวเลข หน่วย และข้อความกำกวม | ไม่เปลี่ยนสาระที่ต้องใช้ |
| เวลาและต้นทุน | งานผ่านกับงานต้องทำใหม่ | นับจนได้ผลที่ตรวจใช้ได้ |
| การดูแลรุ่น | ฉบับเดิม ฉบับย่อ และเหตุผลอนุมัติ | ย้อนกลับได้เมื่อกรณีใหม่ผิด |

ตารางนี้เป็นเกณฑ์เลือก prompt ที่เสนอ ไม่ใช่ตัวเลขประสิทธิภาพที่วัดแล้ว หากงานสำคัญผิดแม้คะแนนเฉลี่ยผ่าน ให้คงคำสั่งเดิมส่วนนั้นและเก็บตัวอย่างไว้แก้การประเมิน
